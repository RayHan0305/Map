# 贝Ki-Map

> To Kinsley

以互动卫星地球为首页的中文旅行相册。用地图或时间线重访城市和拍摄点，也可以在独立影集里浏览、旋转、裁剪和编辑照片备注。

**公开网站** · [贝Ki-Map](https://rayhan0305.github.io/Map/) · [伦敦示例影集](https://rayhan0305.github.io/Map/album.html?id=city-london)

## 体验方式

- 从地图进入国家、城市和拍摄点，或从「旅程」按日期查看相册。示例依次为雷克雅未克、伦敦、大庆。
- 在地球或街道地图上选点，也可以搜索地址或输入经纬度。上传支持批量选图和确认可读取的照片 GPS。
- 首页可以点击花花重访城市、点泡泡查看最近的旅程，或点毛毛添加照片。生日开场可以跳过、关闭和重新开启。

## 照片存在哪里

个人上传的原图、地点、日期、备注和编辑保存在上传时所用浏览器的 IndexedDB 中。公开仓库包含网页源码和可分发的示例素材。换域名或换设备时，用原浏览器打开原网址，在页面底部的「相册备份与迁移」导出 JSON，再到目标网站导入。[详细备份和找回步骤](TRAVEL-GLOBE.md#相册备份与找回)

## 本地运行

安装 Python 3 后，在仓库根目录运行以下命令。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

在浏览器打开本机地址。代码和示例素材在 `main` 的 `dist/`，GitHub Pages 从 `gh-pages` 分支根目录发布。[本机预览](http://127.0.0.1:8000/) · [部署、验收和素材来源](TRAVEL-GLOBE.md)
